## Важно про логотип
SVG используют шрифт Cormorant Garamond по имени. Если он не установлен у зрителя, браузер подставит запасной.
Чтобы логотип был одинаковым везде: открой wordmark в Figma, напечатай заново шрифтом Cormorant Garamond (Medium),
затем Object → Outline stroke / Flatten, и экспортируй как SVG уже кривыми.
